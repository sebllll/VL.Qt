# VL.Qt

Qt 6 (Qt Quick) for [vvvv gamma](https://visualprogramming.net), focused on 2D graphics content: motion, typography and layout. The package ships the Qt runtime for Windows and Linux (x64, arm64), so there is nothing else to install.

## Install

Add `VL.Qt` to the dependencies of your vvvv patch (or install it with the vvvv command line: `nuget install VL.Qt`). The help patches (`HowTo ...`) are in the Help Browser under `Qt`.
