# VL.Qt 0.10.1

A bugfix release for 0.10.0. Nothing changes a patch: nodes, pins and defaults are the same, and patches saved with 0.10.0 open unchanged.

## Fixes

- QML elements: when a `QmlElement` gets another `File`, or a node generated from a `.qml` file takes the place of another one, the property values set for the old file no longer reach the new one. Before, the node showed lines such as `label: the root has no such property` for every property the new file does not declare.

## Docs

- [shapes.md](../shapes.md) names the pins as the nodes have them: `Fill Color` (not `Fill`), and `Opacity` is an optional pin on `Line`, `Polyline` and `Polygon`.
- [user-qml.md](../user-qml.md) says what a new `File` does with the values of the `Properties` dictionary.

## For contributors

- The help texts of the library build without warnings (XML-doc references to the wire protocol resolve).
- SmokeTest: synthetic mouse and wheel input comes from a test mouse of its own, so a real cursor over a test window can no longer cancel a held press (long press, auto repeat). A failing run is kept in `build/smoke-failed/`, and the device-lost retry logs where its time goes.
