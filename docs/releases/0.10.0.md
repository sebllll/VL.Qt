# VL.Qt 0.10.0

VL.Qt 0.10.0 is the large clean-up before VL.Qt goes public. Node, pin and category names now follow the conventions of VL.Skia, VL.ImGui and VL.Stride, and many bugs, leaks and crashes are fixed underneath.
Before 1.0 a minor release may break patches, and this one does: a patch saved with 0.9.x shows red nodes and red links where a name changed. Replace the node, or relink the renamed pin, using the tables below.

## Breaking changes

### Categories

Types and nodes now live under `Qt` only; the second tree `VL.Qt.*` is gone. A type annotation in a patch (for example `QtImage`, `BlendMode`) may need to be picked again.

| Node or type | Before | Now |
|---|---|---|
| all types of `VL.Qt.*` | `VL.Qt`, `VL.Qt.Elements`, `VL.Qt.Nodes`, … | `Qt`, `Qt.Elements`, `Qt.Images`, … |
| `BlendMode`, `LabelPosition`, `ToggleLook` (enums) | `VL.Qt.Nodes` | `Qt.Elements` |
| `QtImage`, `QtImageState` | `VL.Qt` / `Qt` | `Qt.Images` |
| `Blur`, `ColorAdjust`, `Colorize`, `DropShadow`, `Mask` | `Qt.Effects.MultiEffect` | `Qt.Effects` |
| `LoadImage`, `LoadImage (Async)`, `ToQtImage`, `VideoSourceToQtImage`, `Snapshot`, `FileWriter`, `FileWriter (Element)` | `Qt` | `Qt.Images` |
| `ShaderEffect` | `Qt.Elements` | `Qt.Elements.Shaders` |
| `QmlElement` | `Qt.Elements` | `Qt.Elements.Qml` |
| uniform nodes `Float`, `Int`, `Bool`, `Vector2`, `Vector3`, `Vector4`, `Color`, `Matrix`, `Texture`, `Image` | `Qt.Elements.Uniform` | `Qt.Elements.Shaders.Uniform` (names unchanged) |
| `Sampler` | `Qt.Elements.Uniform` | `Qt.Elements.Shaders` |
| `QtTexture` | `Qt` | `Stride.Textures.Source` |
| `ToTexturePixels` | `Qt` | `Stride.Input` |

`Qt` itself keeps `Renderer`, `WindowSettings`, `LoadFont` and `TooltipPreview`.

### Elements

| Node | Before | Now |
|---|---|---|
| `Rectangle`, `Circle` | pin `Color` | pin `Fill Color` |
| `Polygon`, `Path` | pin `Fill` | pin `Fill Color` |
| `Group (Spectral)`, `Row (Spectral)`, `Column (Spectral)` | pin `Children` | pin `Input` |
| `Labeled` | pin `Element` | pin `Input` |
| `Image` | `Fill Mode` of type `ImageFillMode` | type `FillMode` (`Stretch`, `Fit`, `Crop`, `Tile`) |
| `Video`, `Video (VL.Audio)` | `Fill Mode` of type `VideoFillMode` | type `FillMode`; `Tile` draws as `Stretch` with a warning at the node |
| `Text` | `Weight` of type `FontWeight` (enum) | `Weight` is a number, default `400` |

- The enum `FontWeight` is removed. Font weights are numbers from 1 to 1000 everywhere (100 Thin, 400 Normal, 700 Bold, 900 Black), so variable fonts can use any weight.
- One element type, `IElement`, is used on every input and output. The element classes (`Button`, `CheckBox`, `Rectangle`, …) no longer show up as types or nodes in the node browser.
- `Size` is an optional pin, after `Auto Size`, on every node whose `Auto Size` is on by default: `Group`, `Row`, `Column` and their Spectral versions, `ShaderEffect`, `QmlElement`, the widgets and the generated QML and shader nodes. Links stay; an IOBox on `Size` is hidden until the pin is shown.
- Pin order changed on `Labeled` (label pins together: `Text`, `Label Position`, `Label Width`, `Label Height`) and on `QmlElement` (`Auto Size`, `Size`, `Transform`, `Anchor` before `File` and `Properties`). Links are kept; only the layout of the node changes.
- `Polygon`: the default `Stroke Color` is black (was white).
- `Row` and `Column` skip children whose `Enabled` is off: they take no space and the next children move up. Use `Opacity` 0 to keep the gap.
- Long texts (over about 64 KB) and shapes with more than 8,190 points no longer hit a limit; the old warning is gone.

### Widgets

| Node | Before | Now |
|---|---|---|
| `TextInput` | node `TextInput` | node `Input (String)` (search words `text`, `textfield`) |
| `Slider` | node `Slider` | node `Slider (Float)` |
| `Slider (Float)`, `Toggle`, `Input (Int)`, `Input (String)` | output `Bang` | output `Has Changed` |
| `Button` | pin `Is Clicked` | pin `On Click`, now directly after `Anchor` |

- `Button` keeps its `Bang` output.
- The channel is the truth of a widget: `Slider (Float)` and `Input (Int)` show the channel's value clamped to `Min`..`Max`, but no longer write the clamped value back. Widening the range shows the channel value again.

### Interaction

| Node | Before | Now |
|---|---|---|
| `Touch Points` | node `Touch Points` | node `TouchPoints` |
| `Click` | `Is Clicked`, `Long Pressed` | `On Click`, `On Long Press` |
| `Drag` | `Delta`, `Minimum`, `Maximum` | `Translation`, `Min`, `Max` |
| `Pinch` | `Is Active`, `Minimum Point Count`, `Maximum Point Count` | `Is Pinching`, `Min Point Count`, `Max Point Count` |

- `Drag`: `Translation` is the offset since the press, the same word as on `Pinch`. A channel linked to `Translation` is only written after the first drag, so a global channel or preset is no longer reset to `0, 0` when the node is created.
- `Is Hovered`, `Is Pressed` and the widget states of an element shown in several places are true while any of the places is hovered or pressed.

### Effects and shaders

| Node | Before | Now |
|---|---|---|
| `Blur` | `Max`, `Multiplier` | `Max Radius`, `Radius Multiplier` |
| `DropShadow` | `Blur` | `Blur Amount` |
| `Blend` | `Mode` | `Blend Mode` |
| `DirectionalBlur` | `Angle` in degrees | `Angle` in cycles (0.25 = 90°) |
| `RadialBlur` | `Angle` in degrees, default `8` | `Angle` in cycles, default `0.05` |
| `ColorAdjust` | `Saturation` -1..1, default -1 | `Saturation` 0..2 as in HSCB (1 unchanged, 0 grey), default 0 |

- Every effect length is in DIP, in every renderer space: `Blur` `Max Radius`, the `Padding` pins, the `@padding` of a shader file and the length uniforms of shader files. A `@padding 6` used to be 600 DIP per side in the default space; now it is 6 DIP. Patches that compensated for this need smaller values.
- Angle uniforms of the built-in shaders and templates are in cycles.
- The margins of an effect chain (padding, auto padding of blurs) are limited per side to the larger side of the window, at least 1024 DIP. A cut margin shows as an error at the element's node.
- A uniform named like a value VL.Qt sets itself (`source`, `qt_Opacity`, …) is an error at the node; all reserved names are in one list in the docs.

### QML

- A QML property or signal argument of type `point` or `size` gets a `Vector2` pin. A signal argument of that type used to arrive as a string.
- The common pins of the generated QML nodes are in the same order as on `QmlElement`: `Auto Size`, `Size`, `Transform`, `Anchor`, … `Enabled`.
- QML animations follow the clock forward and stop with it; jumping the clock back does not rewind them (now documented).

### Paths

| Node | Before | Now |
|---|---|---|
| `AddCircle`, `AddRoundRect` | pin `Dir` | pin `Direction` |
| `CubicTo`, `CubicTo (Relative)` | pin `EndPoint` | pin `End Point` |
| `AddPoly` | pin `Close` | pin `Closed` |
| `AddArc`, `AddOval` | `Bounds` default `0, 0, 0, 0` | `0, 0, 1, 1` |
| `AddRect`, `AddRoundRect` | `Rectangle` default `0, 0, 0, 0` | `0, 0, 1, 1` |
| `AddArc` | `Sweep Angle` default `0` | `0.25` |
| `AddRoundRect` | `Radius` default `0, 0` | `0.1, 0.1` |

The path nodes now draw like VL.Skia:

- `AddRoundRect` scales radii that do not fit by one common factor, so a large radius gives semicircular ends. The contour starts on the left edge, as in Skia.
- `AddArc` with a full sweep starts the oval at `Start Angle` (it used to ignore it).
- `Spline (CatmullRom)` clamps `Tension` and `Alpha` to 0..1; NaN counts as the default.

This matters for dashes, trim and caps that depend on the start point.

### Styles

The style nodes follow the vvvv record convention: a value reads as `Radius` and writes as `SetRadius`.

| Before | Now |
|---|---|
| setters `Colors`, `Frame`, `Text`, `Indicator`, `Track` | `SetColors`, `SetFrame`, `SetText`, `SetIndicator`, `SetTrack` |
| single setters (`Radius`, `Color`, `FontSize`, … in `Qt.Style.Frame`, `.Text`, `.Indicator`, `.Track`) | `SetRadius`, `SetColor`, `SetFontSize`, … |
| getters `GetColors`, `GetFrame`, `GetText`, `GetIndicator`, `GetTrack` | `Colors`, `Frame`, `Text`, `Indicator`, `Track` |
| single getters `GetRadius`, `GetColor`, `GetFontSize`, … | `Radius`, `Color`, `FontSize`, … |
| pin `State` on every setter | `States` (the getters keep `State`) |

- The six bundle nodes (`SetColors`, `SetFrame`, `SetText`, `SetIndicator`, `SetTrack`, `Merge`) are process nodes now: they cache their output instead of building a new style every frame.
- `Font Weight` is a number on every style node (see Elements).
- Sizes in a style are DIP (only the docs changed; values are the same).

### Images and files

| Node | Before | Now |
|---|---|---|
| `Snapshot`, `FileWriter (Element)` | pin `Element` | pin `Input` |
| `VideoSourceToQtImage` | output `Output` | output `Image` |

- The `Error` outputs of `LoadImage`, `LoadImage (Async)`, `ToQtImage`, `VideoSourceToQtImage`, `Snapshot`, `FileWriter`, `FileWriter (Element)` and `LoadFont` are removed. Errors go to the vvvv log; a failed load also marks the node until an input changes.
- `FileWriter` and `FileWriter (Element)` have a new output `Success` next to `Is Done`.
- `ToQtImage` keeps one `QtImage` and replaces its content. A downstream `S+H` or change check no longer sees a new instance every time.
- A `QtImage` that its node released (it loaded another image or was deleted) reports `Failed` instead of staying `Ready`; the reason is in the log.

### Renderer

- The `Error` output is removed. All messages show at the node, one line each, and go to the log.
- `WindowSettings` keeps only `Icon` and `Bounds`. Set `Title`, `Borderless` and `Fullscreen` on the `Renderer`.
- `Perf` (`PerfStats`) is regrouped: the main values stay on `Split`, the rest moved into grouped values with their own `Split` (`Percentiles`, `Counters`, `Recent`, `Host`, `Gc`). The operations `SplitPercentiles`, `SplitCounters`, `SplitVsync`, `SplitHost` and `SplitGc` are removed. New values: `Work Ms`, `Vsync Ms`.
- Frame statistics come from consecutive frames only. An idle scene shows `Fps` 0 instead of a misleading "2 fps", and `Over Budget` counts only Qt's own work, not the wait for vsync.
- A `vlqt` library of another version than the `VL.Qt` assembly is refused: no window, the log names both versions and the node is marked.
- The nodes `ToQtAlignment` and `AnchorOffset` are removed (they were internal helpers).

### Stride (VL.Qt.Stride)

- `QtTexture`: the `Error` and `Perf` outputs are removed. Errors go to the log and mark the node.
- `QtTexture`: `Multisample Count` uses Stride's `MultisampleCount` enum; the `Renderer` keeps VL.Qt's own.
- `QtRenderer`: the `Error` output is removed; the blend hint and errors show as a warning at the node.
- `QtRenderer` draws into one target per frame. A second, different target in the same frame is not drawn and the node says so; use one `QtRenderer` per window.
- `QtRenderer` stops rendering its scene while its layer is not drawn.

### Video (VL.Audio)

- The node is marked Experimental until it has been measured on x64.
- The audio latency is taken from the running stream. The sound may move by a few milliseconds, so check an `Audio Offset` calibration.

## New

- `Enabled` (optional, default on) on every element node and on the generated QML and shader nodes. Off, the element is not drawn and takes no space in `Row` and `Column`.
- `Style` (optional) on `Row`, `Column`, `Row (Spectral)` and `Column (Spectral)`.
- `Clip` and `Debug` (optional) on `Labeled`.
- `Apply` (optional, default on) on every effect node: off passes the chain on unchanged, so an effect can be switched without relinking.
- `Renderer`: `Enable Keyboard Shortcuts` (optional, default on). Off, F2, F5, F6 and F7 reach the patch instead of the stats overlay.
- `QtTexture`, `QtRenderer`: `Render Threads` (optional, default 1; 0 renders on the main thread).
- `LoadImage`, `LoadImage (Async)`, `ToQtImage`, `VideoSourceToQtImage`: `Upload` (optional: `Auto`, `MainThread`, `Worker`), for measurements.
- `FileWriter`, `FileWriter (Element)`: output `Success`. 16-bit and float images are written as 16-bit PNG; other formats get 8 bit and a warning in the log.
- Shader files: the annotations `@optional` (pin hidden until shown), `@tags` (search words) and `@remarks` (longer help). `@category` can be relative and takes effect at once.
- Shader files: `texelSize`, `dpr` and `viewSize` are set by VL.Qt on the element node, so a shader can work in DIP. The RGBSplit template uses them.
- Pin names of shader uniforms are split before a digit (`offset2` becomes `Offset 2`).
- QML and shader files that fail to load or compile keep their last good pins and links, and the error shows at the node. The last good shader keeps drawing; a QML node stays empty until its file compiles again.
- The tooltip of a style shows what it sets, for example `Frame.Color[Normal,Hovered], Text.FontSize[All]`.

## Fixes

- arm64 (Windows and Linux): native crashes in the effects path are fixed, among them the zoom and directional blurs.
- An exception inside the update of the scene no longer leaks resources every frame; the scene is rebuilt in the next frame and the `Renderer` is marked.
- A non-finite value (NaN, infinity) on a numeric pin is refused with a message instead of reaching Qt.
- A rejected effect chain no longer makes an unrelated element disappear.
- Textures of image uniforms are freed on their render thread (leak and possible crash).
- A failed creation of the GPU device is retried once per second instead of lasting until restart.
- The bounds of a `Group` that contains a nested `Group` reaching left of or above its origin are right (hit area, clip, effect padding, debug overlay).
- Messages at a node are no longer lost: every warning and error is shown, and a recovering part no longer clears another part's warning.
- `Labeled` clears the messages of the inactive layout when `Label Position` changes.
- `QmlElement` updates its message when an unsupported property value changes to another unsupported type.
- Generated QML nodes: a file with a regex literal parses and keeps its pins.
- Generated QML nodes and `QmlElement`: a root with `required property` loads.
- Generated QML nodes: a file whose root is its own type shows an error instead of a cycle warning.
- Generated shader nodes: no false "set more than once" message on image pins.
- Generated shader nodes: a uniform block that does not use binding 0 shows an error at the node.
- Generated shader effect nodes: a uniform called `size`, `opacity` or `transform` keeps its plain pin name.
- Generated shader effect nodes: a `@chainonly` file without `source` shows its node with an error instead of only a log line.
- Two `Sampler`s of one shader reading the same element no longer lose the mip filter.
- A stylable widget used as an effect mask or uniform texture is rebuilt when its style changes.
- `LoadImage (Async)`: with `Keep Previous` off, a failed load clears the output at once.
- `FileWriter (Element)`: when `Write` is triggered twice quickly, the newest grab is written.
- `Renderer`: a patch that sets `Bounds` through `WindowSettings` is no longer marked as changed right after opening.
- `Renderer` used from the wrong thread shows an error at the node, also in Release builds.
- Qt animations no longer jump back when a `QtTexture` runs in a second vvvv app in the same process.
- Exported apps that use only `QtTexture` or `FileWriter` exit cleanly (exit code, no hang on Linux arm64).
- Less work per frame: unchanged effect chains, uniforms and the debug overlay no longer allocate or repaint.

## Platforms

- Windows x64 and Windows arm64: built and tested by CI. `VL.Qt.Stride` and `VL.Qt.Audio` are Windows only.
- Linux x64 and Linux arm64: console export with its own Qt window, tested under WSL2 with WSLg.

## For contributors

Nothing here changes a patch; it changes where code lives and how it is tested. Start with [AGENTS.md](../../AGENTS.md), [development.md](../contributing/development.md) and [architecture.md](../contributing/architecture.md).

- QtNative is cut into one folder per area (`app`, `scene`, `effects`, `resources`, `device`, `offscreen`, `elements`, `qml`, `window`, …). Every use of a private Qt class is listed in the head comment of `elements/elements.h`.
- The C API and the wire protocol follow the [glossary](../glossary.md): u32 lengths without caps or chunking, one bounds-checked wire reader, one op table for all commands, one result table and a per-thread last error. A `vlqt` library of another ABI version is refused. Unit tests check `protocol.h` and `vlqt.h` against their C# mirrors.
- The C# library has one folder per area (`Nodes` per category, `Reconciliation`, `Wire`, `Interop`, `Qml`, `Shaders`, `Styles`, …). The reconciler is split into types with one job each; every element pin uses `IElement`; messages at a node go through one mechanism.
- Tests: the SmokeTest runs on NUnit, compares WARP reference images and replays command traces recorded from help patches; decoder fuzzing; tests for the Stride layer; a snapshot of the whole public node API (`src/VL.Qt.Tests/Api/node-api.txt`) that a change of a node, pin or type must regenerate. The test hooks left the library and QtNative (`testkit`, `vlqt_test.h`).
- The gate `tools/build.ps1 -Test` also runs `tools/check-source-rules.py`; `tools/test-linux.sh` runs everything under Linux, with `--sanitize asan|tsan` for QtNative.
- Renamed nodes and pins reach the help patches through `tools/vl-patch-mapping.txt` and `tools/vl-patch-migrate.py`; `tools/vl-patch-check.py` reads `node-api.txt`.
- Docs are split by audience: user pages in `docs/`, [contributing](../contributing/) with the walkthrough [add-an-element.md](../contributing/add-an-element.md), [design notes](../design/) for the reasons behind decisions, [research](../research/) for measurements.
