## 6. How to sign

When You open a pull request, a bot checks whether You have signed. If not, it posts a comment with this agreement. To sign, reply to the bot's comment in the pull request with exactly this sentence:

> I have read the CLA Document and I hereby sign the CLA

The bot records Your GitHub user name and the date of Your comment in a signature file in the repository. Your comment is Your electronic signature. The pull request can only be merged once all its authors have signed.
